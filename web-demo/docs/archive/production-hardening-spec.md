## 완료 기준

- 배경 별무리는 새로고침해도 동일하고, 항성 데이터·라벨·경로와 시각적으로 구별된다.
- 지구와 목적지, 현재 탐색 별, 반경 질의 이웃, 확정 별, 최종 경로가 서로 구분된다.
- 비행 중 우주선이 그리는 궤적 끝에 위치하고, 경유 시 정지와 목적지 도착 상태가 알아보기 쉽다.
- 자동 카메라 추적은 대상이 화면에 남도록 하고, 사용자가 회전·확대하면 추적이 물러난다. 시점 초기화는 시작 구도를 복원한다.
- 화면 검토 뒤에도 샌드박스, `X=8 ly`, 단계 로그와 비용 계산이 기존 규칙과 같다.

완료 여부는 인트로, 탐색 시작, 질의 단계, 최종 경로 재생, 카메라 수동 조작 후 초기화의 다섯 화면 상태를 확인해 기록한다. 이 목록은 화면 품질 확인 기준이며, 제외 항목을 다시 범위에 넣지 않는다.
