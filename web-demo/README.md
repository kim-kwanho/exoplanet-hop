# 웹 시각화 확장 작업 공간

이 디렉터리는 주제 B 필수 제출물과 별도인 교육용 웹 시각화 확장을 위한 자리다. 과제의 알고리즘 모형은 외계행성 호스트 별 사이 경로이고, 사용자가 제안한 웹 확장은 태양계에 한정한 실시간 연동 환경이므로 **같은 데이터·같은 모형이라고 섞어 쓰지 않는다.** 공통으로 재사용할 수 있는 것은 거리 단위 처리와 경로 탐색 설명이다.

## 시작 전에 결정할 항목

- 무엇을 실시간으로 연동할지: 천체 위치, 거리, 또는 경로 계산
- “실시간”의 의미와 데이터 갱신 간격
- 대상 천체와 목적지 선택 방식
- X, 이동 속도, 정차/기착 시간을 웹에서 어떻게 설정할지
- 공개 데이터 API와 사용 조건
- 웹 시각화가 보여줄 알고리즘 단계와 사용자 입력

## 초기 구조 제안

- `src/`: 화면과 경로 계산
- `public/`: 정적 이미지·아이콘
- `data/`: 출처가 명확한 샘플 데이터만 보관
- `docs/`: 데이터 형식과 배포 절차

아직 앱 프레임워크나 외부 API는 선택하지 않았다. 범위와 데이터 원천을 정한 다음 초기화한다.
