# 가정

과제 PDF에 밝힐 단순화. 제미나이 문장을 그대로 쓰지 않는다.

| 가정 | 과제에 밝힐 이유 | 출처 또는 근거 |
|---|---|---|
| 노드는 발견된 호스트 별만. 행성이 여러 개여도 `hostname` 하나 | 지도가 전체 하늘이 아님 | 프로젝트 정의 |
| 지구는 원점이고 아카이브 행이 아님 | 출발점 | 프로젝트 정의 |
| 위치는 측정 시각에 고정. 고유운동은 넣지 않음 | 좌표가 시간에 따라 변하지 않게 함 | 프로젝트 정의 |
| 쌍성도 계의 위치 한 점 | 항성 사이 거리를 경로에 넣지 않음 | 프로젝트 정의. `sy_snum`, `cb_flag`는 열 정의에 있음 |
| 이동은 3차원 직선. 중력, 상대론은 넣지 않음 | 가중치가 유클리드 거리로 정해짐 | 프로젝트 정의 |
| 좌표는 `sy_dist`만 사용하고 오차 열은 한계로만 적음 | 점이 하나가 아니면 간선 여부가 흔들림 | 열 정의. 오차를 무시하는 것은 단순화 |
| 간선은 직선거리 ≤ X | X가 없으면 직선이 항상 더 짧음 | 프로젝트 정의 |
| 가중치는 거리/속도 + 기착 고정 시간 | 비용의 단위를 시간으로 둠 | 프로젝트 정의 |
| 표는 `pscomppars`를 우선 후보로 둠 | 행성당 한 행이라 중복이 적음 | [PS 열 정의](https://exoplanetarchive.ipac.caltech.edu/docs/API_PS_columns.html). 거리 결측이 더 적은지는 다운로드 후에 센다 |

아직 확인되지 않아 가정으로 확정하지 않는 것: 같은 `hostname`의 `ra`, `dec`, `sy_dist`가 항상 같다.
