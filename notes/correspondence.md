# 현실-알고리즘 대응표 (확정안)

이 표는 주제 B의 외계행성 호스트 별 경로 계획 모형을 정의한다. X=15광년, 일정 속도 0.1c, 경유 별당 1년 기착, 목적지 도착 후 기착 없음으로 둔다.

| 현실 | 알고리즘 | 정의 |
|---|---|---|
| 지구/태양계 위치 | 출발 정점 S | 아카이브 별 데이터와 별도로 둔다. S에서 X 이내 호스트 별을 k-d 트리로 처음 질의한다. |
| 확인된 외계행성 호스트 항성계 | 정점 | 행성이 여러 개여도 `hostname`당 정점 하나. 거리·좌표가 없는 계는 제외한다. |
| 두 위치 사이 직선거리 ≤ 15광년 | 도약 가능 연결 | 별-별 연결 가능 여부는 무방향이다. 좌표와 X를 같은 단위(광년)로 맞춘다. |
| 한 도약의 순항 시간 | 간선 비용의 기본 항 | 유클리드 거리 / (0.1c). 거리 광년, 속도 광년/년으로 계산해 시간을 년 단위로 얻는다. |
| 경유 호스트 별에서 머무는 시간 | 전이 비용 | 호스트 별에서 다음 도약을 출발할 때 1년을 더한다. 목적지에서는 탐색을 끝내므로 기착 비용이 없다. |
| 현재 위치에서 15광년 안의 호스트 별 | k-d 트리 반경 질의 결과 | 초기에는 지구 출발점에서 질의하고, 이후 다익스트라가 확정한 각 호스트 별에서 질의한다. |
| 누적 이동 시간 최소 | 다익스트라의 거리 레이블 | 지금까지의 순항 시간과 이미 마친 경유 기착 시간의 합. |
| 지구에서 목적지까지 최저 총시간 경로 | 직전 정점 기록으로 복원한 경로 | 목적지를 다익스트라가 최소 레이블로 확정할 때 종료한다. |

## 확정 가정

- 지구는 외계행성 아카이브 행이 아니므로 별도 출발 정점 S로 둔다. 천문 좌표의 태양계 원점을 지구 위치의 근사로 사용한다.
- 지도에는 발견된 행성의 호스트 항성계만 들어간다. 행성이 여러 개여도 한 항성계를 한 점으로 표현한다.
- 위치는 관측 자료 시점에 고정한다. 고유운동과 은하 회전은 반영하지 않는다.
- 모든 도약은 3차원 직선 경로로 계산한다. 항성 중력, 상대론적 효과, 가속·감속 구간은 제외한다.
- 속도는 전 구간에서 0.1c로 일정하다고 가정한다. 이는 알고리즘 계산용이지 현재 기술의 성능 주장이 아니다.
- 최대 도약 거리는 15광년이다. 이는 분석용 기준값이며, 실제 데이터에서 목적지까지 연결되는지 검증한다.
- 목적지 전 경유하는 각 호스트 별에서 다음 도약 전 1년 머문다. 목적지 도착 후에는 머무는 시간을 더하지 않는다.
- 좌표 오차는 기본 경로 계산에서 무시한다. 거리 오차는 실제 도약 가능 여부가 달라질 수 있는 한계로 설명한다.
- `sy_dist`가 비어 3차원 좌표를 만들 수 없는 호스트는 정점에서 제외한다.

## 경로 비용 정의

전이 u→v의 비용은 `거리(u,v)/(0.1c) + (출발점 u가 호스트 별이면 1년, 지구이면 0년)`이다. 목적지에 도달하면 탐색을 종료하므로 목적지에서의 기착 비용은 붙지 않는다. 도약 연결 여부는 대칭이지만, 출발 호스트에서 기착 시간을 더하므로 전이 비용은 방향에 따라 달라질 수 있다. 모든 비용이 음수가 아니므로 다익스트라를 적용할 수 있다.

## 좌표와 단위

아카이브의 `ra`, `dec`는 각도이고 `sy_dist`는 파섹이다. 각도를 라디안으로 바꾸어 3차원 직교좌표로 변환한 뒤, 좌표와 X를 모두 광년으로 통일해 유클리드 거리와 반경 질의를 계산한다. 환산 계수와 출처는 `numbers.md`에 기록한다.
