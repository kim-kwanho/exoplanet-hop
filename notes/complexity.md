# 복잡도

식만 적는다. 호스트 수 N은 아카이브 화면 숫자가 출처와 함께 확인되기 전에는 넣지 않는다.

## 식

- 전수 거리 계산 횟수의 상한: N(N-1)/2. 무방향 쌍을 한 번씩 볼 때.
- 그 쌍을 모두 저장할 때 메모리: [N(N-1)/2] × (간선 1개의 바이트). 바이트 수는 가정이다. 보고서의 16바이트(정수 둘 + 실수 하나)는 저장 형식을 그렇게 잡을 때의 가정이지, 측정값이 아니다.
- 이진 힙 다익스트라: O((N + E) log N). E는 거리 ≤ X인 간선 수.
- 3차원 k-d 트리 반경 질의: 평균은 O(log N + K)로 두고, K는 반경 안의 개수. 최악은 Lee & Wong (1977)류의 범위 탐색 한계를 쓰려면 논문 페이지를 다시 확인한다. 보고서의 O(N^(2/3) + K)는 그 계열의 식이며, 이 카탈로그에 그대로 적용된다고 적지 않는다.
- 지연 질의에서 각 별을 최대 한 번만 꺼내면, 반경 질의 횟수의 상한은 N이다.

## 확인된 입력

- 없음. 보고서의 N ≈ 4,842는 URL이 없어 보류다.

## 계산

- 아직 하지 않음.

## 사용 가능 여부 판단에 아직 없는 입력

- 거리가 있는 호스트 수 N (다운로드 후).
- 선택한 X에서 간선 수 E. 아카이브가 이 분포를 제공하지 않는다고 보고서는 적었다. 좌표를 받은 뒤에 세야 한다.
- 간선 1개의 바이트를 어떤 저장 형식으로 잡을지.
